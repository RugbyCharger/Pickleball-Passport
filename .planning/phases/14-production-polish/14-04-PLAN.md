<task type="auto">
  <name>Task 1: Create eas.json with build profiles</name>
  <files>mobile/eas.json</files>
  <action>
    Create mobile/eas.json with three build profiles:

    ```json
    {
      "cli": {
        "version": ">= 12.0.0"
      },
      "build": {
        "development": {
          "developmentClient": true,
          "distribution": "internal",
          "ios": {
            "simulator": true
          },
          "android": {
            "buildType": "apk",
            "gradleCommand": ":app:assembleDebug"
          }
        },
        "preview": {
          "distribution": "internal",
          "ios": {
            "simulator": false
          },
          "android": {
            "buildType": "apk"
          }
        },
        "production": {
          "autoIncrement": true,
          "ios": {
            "resourceClass": "medium"
          },
          "android": {
            "buildType": "aab"
          }
        }
      },
      "submit": {
        "production": {
          "ios": {
            "ascAppId": "APP_STORE_CONNECT_APP_ID_PLACEHOLDER"
          },
          "android": {
            "track": "internal",
            "serviceAccountKeyPath": "./google-service-account.json"
          }
        }
      }
    }
    ```

    Profile purposes:
    - development: Local dev with dev client, simulator support
    - preview: Internal testing builds (real devices)
    - production: App store submission builds (AAB for Android, optimized iOS)

    Note: ascAppId and serviceAccountKeyPath are placeholders - user provides in checkpoint.
  </action>
  <verify>
    - `cat mobile/eas.json | grep -A5 production` shows production profile
    - `cat mobile/eas.json | grep submit` shows submit section
    - JSON is valid: `cd mobile && cat eas.json | python3 -m json.tool > /dev/null && echo "Valid JSON"`
  </verify>
  <done>eas.json created with development, preview, and production profiles</done>
</task>

    4. **Run EAS credentials check:**
