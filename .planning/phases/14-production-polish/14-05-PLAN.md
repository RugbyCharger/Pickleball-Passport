<task type="auto">
  <name>Task 2: Build production iOS and Android apps</name>
  <files>mobile/app.json</files>
  <action>
    1. Ensure all placeholders in mobile/app.json are replaced with real values

    2. Build iOS production app:
       ```bash
       cd mobile && npx eas build --platform ios --profile production
       ```
       This will:
       - Generate/use iOS distribution certificate
       - Generate/use provisioning profile
       - Build the IPA file
       - Upload to EAS servers

    3. Build Android production app:
       ```bash
       cd mobile && npx eas build --platform android --profile production
       ```
       This will:
       - Generate/use Android signing keystore
       - Build the AAB file
       - Upload to EAS servers

    4. Wait for builds to complete (10-30 minutes each)
       Monitor at: https://expo.dev/accounts/[username]/projects/pickleball-passport/builds

    Note: If this is the first build, EAS will prompt to create credentials. Follow the prompts.
  </action>

    - EAS build dashboard shows completed Android build
    - No build errors in logs
  </verify>
