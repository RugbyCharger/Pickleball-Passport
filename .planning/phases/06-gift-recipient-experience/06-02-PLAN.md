**2. State and Hooks:**
- `viewMode` state with types above
- `errorMessage` state for error display
- `declineReason` state (optional string, max 500 chars)
- `token` from searchParams

- `trpc.gift.declineGift.useMutation` with onSuccess/onError

**3. View Modes:**

**Loading State:** Same spinner pattern as accept page

**Error State:** Same card pattern with XCircle icon, show errorMessage

**Gift Details View:**
- Header: "Decline This Gift?" with AlertTriangle icon (yellow/amber gradient)
- Show gift details summary (package name, duration, from purchaser name)
- Personal message if present (same styling as accept page)
- Warning box: "Are you sure?" explaining refund to purchaser
- Optional textarea for decline reason (label: "Reason (optional)", placeholder: "Let them know why you're declining...")
- Two buttons:
  - "Go Back" (outline) - `router.back()` or `router.push('/gift/accept?token=' + token)`
  - "Yes, Decline Gift" (destructive variant) - triggers decline mutation

**Confirming State:** Loader with "Processing your request..."

**Success State:**
- Green checkmark
- "Gift Declined" title
- Message: "The purchaser has been notified and will receive a full refund."
- "Go to Home Page" button

**4. Key Implementation Details:**
- Use `bg-gradient-to-b from-amber-50 to-background` for decline page background
- Destructive button: `className="w-full bg-destructive hover:bg-destructive/90"`
- Don't require authentication (matches declineGift being publicProcedure)
- Include same formatCurrency and formatDate helpers from accept page
- Handle mutation loading state (disable button, show spinner)
