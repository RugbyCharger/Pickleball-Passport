<objective>
Remove legacy PartnerPayoutMethod model and related code in favor of exclusive Stripe Connect usage.

Purpose: The codebase has full Stripe Connect integration for partner payouts (verified in 01-RESEARCH.md). The legacy PartnerPayoutMethod model stores plaintext bank account data which is a PCI compliance risk and security concern. All payout functionality should use Stripe Connect exclusively.

Output: A clean codebase where:
1. PartnerPayoutMethod model is removed from schema
2. updatePayoutSettings and getPayoutSettings tRPC procedures are removed
3. Payouts UI only shows Stripe Connect (no legacy bank form)
4. Database migration removes the table
</objective>
