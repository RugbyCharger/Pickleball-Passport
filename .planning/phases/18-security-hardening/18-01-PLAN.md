<task type="auto">
  <name>Task 2: Add ESLint no-console Rule</name>
  <files>eslint.config.mjs</files>
  <action>
Update eslint.config.mjs to add a no-console rule that prevents new console.log statements from being added.

Import the rules configuration and add the no-console rule:

```typescript
import { defineConfig, globalIgnores } from "eslint/config";
import nextVitals from "eslint-config-next/core-web-vitals";
import nextTs from "eslint-config-next/typescript";

const eslintConfig = defineConfig([
  ...nextVitals,
  ...nextTs,
  // No console.log in production code (SEC-04)
  {
    rules: {
      'no-console': ['error', { allow: ['warn', 'error'] }],
    },
  },
  // Allow console in scripts and tests
  {
    files: ['scripts/**/*.ts', '**/*.test.ts', '**/*.spec.ts', 'prisma/seed.ts'],
    rules: {
      'no-console': 'off',
    },
  },
  globalIgnores([
    // Build outputs
    ".next/**",
    "out/**",
    "dist/**",
    "build/**",
    "next-env.d.ts",
    // Generated/report files
    "playwright-report/**",
    "test-results/**",
    "coverage/**",
    // Dependencies
    "node_modules/**",
    // Cache
    ".cache/**",
    ".turbo/**",
    // Prisma generated
    "prisma/generated/**",
    // Public assets (not code)
    "public/**",
    // Mobile app (separate lint config)
    "mobile/**",
  ]),
]);

export default eslintConfig;
```

This:
1. Errors on console.log (forcing pino usage)
2. Allows console.warn and console.error as escape hatches
3. Exempts scripts/, test files, and seed.ts where console is acceptable
4. Ignores mobile/ directory (separate app with different lint config)
  </action>

  </verify>
  <done>
ESLint config includes no-console rule at error level with appropriate exemptions for scripts and tests.
