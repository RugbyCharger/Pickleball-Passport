## Tech Debt

### Phase 18: Security Hardening

**Priority: Medium**

1. **23 console.log statements in lib/ directory**
   - Files: send-pre-trip-emails.ts (5), send-post-trip-emails.ts (5), receipt-generator.ts (3), push/index.ts (1), application.ts (2), partner.ts (1), app/r/[code]/route.ts (2)
   - Impact: Bypasses PII redaction and structured logging
   - ESLint is catching these as errors (visible to developers)
   - Action: Migrate to emailLogger, pdfLogger, etc.

2. **firstName/lastName not in PII redaction paths**
   - Fields used in: GuestProfile, PartnerProfile, Application
   - Currently logged in agent/context route
   - Action: Add to lib/logger/index.ts redactPaths

3. **ESLint not blocking builds**
   - Rule configured at error level
   - Errors visible in IDE/CI but don't fail build
   - Action: Add `--max-warnings=0` to build script

**Total:** 3 tech debt items
